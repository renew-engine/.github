# `.github`

Organization-wide files for [renew-engine](https://github.com/renew-engine).

- [`profile/README.md`](profile/README.md) — the page shown at
  [github.com/renew-engine](https://github.com/renew-engine).
- [`profile/assets/`](profile/assets) — the brand artwork that page uses. The originals live
  in the engine repository under
  [`assets/brand/`](https://github.com/renew-engine/renew/tree/main/assets/brand); these are
  copies, because a profile page can only reference images stored beside it.

The engine itself is at [renew-engine/renew](https://github.com/renew-engine/renew) — issues
and pull requests belong there, not here.
